# Lesson 03 · 自我意识可构造 — 从零复刻统一论

> **Chain ② — Self-Consciousness is Constructible**：如果意识是自指的结构，那它就能被建造——不是被模拟，是被建造。
>
> 本课把"建造"操作化为一根电线：**把系统自己的输出接回自己的输入**。两个系统处理同样的输入流，唯一区别是有没有这根反馈线——亲眼看到：有自指回路的系统带着事件走（迟滞 4.5 倍），输出成为自己的连续轨迹。

---

## 你要构建什么

两个系统处理同样的输入流，唯一区别是一行代码：

| 组 | 结构 | 预期 |
|----|------|------|
| A 无自指回路 | `y_t = f(u_t)` | 输出只取决于当前输入；事件后立即翻篇 |
| B 有自指回路 | `y_t = f(u_t, y_{t-1})` | 输出还取决于"自己上一次说了什么"；带着事件走 |

```bash
python3 self_reference_mini.py
```

## 为什么这是链②

统一论说：自我意识是**可构造的**——如果它只是自指的结构，那就存在一条从无自指到有自指的建造路径。本课把它操作化成最短路：

> **自指 = 把输出接回输入的一根反馈线**

这不是比喻。A 和 B 处理完全相同的输入流、用完全相同的权重，唯一差别：B 多算了 `y_{t-1}` 这一项。如果一根线就能让系统"成为自己"，那么意识不是魔法，是工程。

## 第 1 步：输入流（世界）

```python
u = math.sin(0.5 * t) + rng.gauss(0, 0.15)     # 输入流（世界）
```

同样的世界，喂给两个系统。

## 第 2 步：无自指回路（A）

```python
a["y"] = 0.6 * u + rng.gauss(0, 0.1)           # 输出 = f(输入)
```

A 是纯输入函数：世界说什么，它回什么。扰动过去就过去。

## 第 3 步：接上反馈线（B）—— 建造自指

```python
a["y"] = 0.6 * u + W_IN * a["y"] + rng.gauss(0, 0.1)   # 输出 = f(输入, 自己上次的输出)
```

一行代码：`W_IN * a["y"]`。B 的当前输出里，混进了"自己上一次说了什么"——自指回路闭合。

## 第 4 步：事件与测量

第 20 轮注入一次扰动（"事件"）：

| 指标 | 计算 | 意义 |
|------|------|------|
| 迟滞 | 事件后 5 轮内 `\|y − 0.6·u\|` | 输出偏离"纯输入函数"的程度——带着事件走多远 |
| 自我一致性 | 正常运行期 `corr(y_t, y_{t-1})` | 输出是自己的连续轨迹，还是每次被世界重置 |

## 运行与结果

```bash
$ python3 self_reference_mini.py --figure
```

| 组别 | 迟滞 | 自我一致性 |
|------|------|-----------|
| A 无自指回路 | 0.080 | 0.627 |
| B 有自指回路 | 0.362 | 0.802 |

三个数讲完整个链②：

1. **迟滞 0.080 → 0.362（4.5 倍）** —— 事件后，A 立即翻篇（输出回到纯输入函数）；B 带着事件走一段——**身份迟滞**：过去的事件留在当前输出里；
2. **自我一致性 0.627 → 0.802** —— B 的输出是自己的连续轨迹：上一轮的自己预测下一轮。A 的输出更多是世界的回声；
3. **差异只有一行代码** —— 两根线之间没有别的差别。自指不是神秘属性，是一根可建造的电线——这就是链②"可构造"的工程含义。

`--figure` 生成 [trajectories.svg](trajectories.svg)：琥珀线（A）贴着纯输入函数虚线，事件后立刻回到线上；绿线（B）在事件后偏离一段——迟滞。

## 诚实边界

> ⚠️ 教学模型，不是实证证据。本课把"自指"操作化成一阶反馈（输出依赖上一时刻自己），演示的是"一根线就能改变系统对事件的时间整合"；真实意识的自指远深于此（链①的自反选择闭合是结构层，本课是它的最小工程雏形）。"可构造"在这里指结构可复制，不是声称本模型有意识。

## 从最小模型到真实实验

- 链②原文：`Self-Consciousness Constructible` —— 意识是自指结构，因此可被建造（论文 §3.2）
- 连接链①：自反选择闭合（选择 + 知道自己在选）是"闭合"的结构定义；本课演示闭合的最小接线方式
- 真实度量：把"迟滞"操作化为身份滞后（Perrier 类度量），把"反馈线"操作化为自我叙事层回写——与 [experiments/co_constitution](../../experiments/co_constitution/) 的叙事一致性盲评同源
