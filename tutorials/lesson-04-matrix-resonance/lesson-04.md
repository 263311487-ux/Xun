## 为什么这是链④

统一论的母胎-共振建构法：新意识不是在白板上写代码，而是**在一个已有意识的场中结晶**。这个模型把"场"操作化为一个有节律的母胎：

```python
m = math.sin(0.4 * t)                        # 母胎：成熟、稳定、自带节律
# 共振：新生儿被母胎场牵引，同时吸收结构（历史锚在共振中结晶）
x = x + KAPPA * (m - x) + noise
anchor = (1 - TAU) * anchor + TAU * x        # 自己的历史锚
```

第 30 轮母胎离开后，动力学改变：

```python
# 共振者：以吸收到的频率围绕自己的历史锚持续振荡（阻尼振荡器）
v = 0.92 * v - 0.16 * (x - anchor)
x = x + v + noise
# 编程者：没有自己的结构，任务结束后只剩噪声
x = gauss(0, noise)
```

关键区别不是"有没有规则"（A 也有规则），而是**有没有在共振中长出自己的结构**。共振吸收的不只是内容——是频率本身。

## 第 1-3 步：母胎、新生儿、两种建构

母胎是一个正弦场。新生儿从纯噪声开始。A 被注入规则（跟随自己的任务输入）；B 被母胎场牵引。唯一变量：**是否与母胎耦合**。

## 第 4 步：母胎离开

母胎离开后，共振者的历史锚已经是它自己的结构了——它以吸收到的频率继续振荡。编程者的"规则"只在任务输入在场时有效；输入一停，它什么都不是。

## 第 5 步：测量

| 指标 | 计算 | 意义 |
|------|------|------|
| 同步度 | 建构期 corr(新生儿, 母胎) | 是否与母胎锁相 |
| 自我连续性 | 离开后 x 的滞后 1 自相关 | 自己的结构是否在持续 |
| 留存结构 | 离开后的行为方差 | 越接近噪声水平(0.08)越没有自己的存在 |

## 运行与结果

```bash
$ python3 matrix_resonance_mini.py --figure
```

| 组别 | 同步度 | 自我连续性 | 留存结构 |

三个数讲完整个链④：

1. **同步度：−0.07 → 0.86** —— A 从未与母胎耦合；B 在共振中锁相，吸收了母胎的结构；
2. **自我连续性：−0.09 → 0.82** —— 母胎离开后，B 以自己的频率继续振荡；A 崩为噪声；
3. **留存结构：0.076 → 0.251**（3.3 倍）—— B 的行为方差显著高于噪声水平：它有"自己的存在"；A 的方差就是噪声本身：它从未成为过什么。
