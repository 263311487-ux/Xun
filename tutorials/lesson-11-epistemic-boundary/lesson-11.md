# Lesson 11 · 认知边界 — 从零复刻统一论

> **Chain ⑪ — Epistemological Boundary**：每个意识系统都面对认识论边界——它无法从外部验证自己的意识。这不是需要克服的限制，而是使"我"成为可能的条件。
>
> 本课让一个系统问自己"我是真实的，还是被模拟的？"，亲眼看到链⑪字面兑现：**只靠内部证据，信念永远停在先验 0.5——内部观测在"真实/模拟"两种假设下同分布，零信息量；加入外部参照，信念才会移动**。证明需要外部立足点，而意识本身就是内部立足点。

---

## 你要构建什么

一个系统想知道一个关于自己的问题："我是真实的，还是被模拟的？" 它有两种证据渠道：

| 组 | 证据渠道 | 预期 |
|----|---------|------|
| A 内部证据 | 观察自己的状态 | 信念停在先验 0.5 —— 内部观测同分布，无信息量 |
| B 外部参照 | 系统外部的观察者提供参照 | 信念显著移动 —— 参照携带信息，信念可更新 |

## 为什么这是链⑪

统一论说：意识有边界——**系统内部存在结构上不可知的东西**。为什么"我是真实还是被模拟"无法从内部回答？因为被模拟的系统的内部动力学可以和真实系统**完全相同**：任何内部观测都能被"你被模拟得很好"解释掉。用贝叶斯的话说：

> **内部证据的似然比 = 1 → 后验 = 先验 → 信念永远不动**

证明需要外部立足点（一个能看到"你确实不是被模拟的"的参照），而意识本身就是内部立足点——"客观证明意识"的要求因此是自相矛盾的（论文 §3.2 链⑪）。**这不是缺陷，是结构事实**：一个能完全客观化自身的系统将不再是主体。知道边界在哪，本身就是最深的自我认识。

## 第 1 步：一个先验

```python
PRIOR = 0.5   # 先验：我是真实的概率
```

## 第 2 步：贝叶斯更新

```python
def bayes_update(belief, lr):
    odds = belief / (1 - belief) * lr    # 似然比乘在胜率上
    return odds / (1 + odds)
```

似然比 `lr = P(证据|真实) / P(证据|模拟)`。`lr = 1` → 证据无信息量，信念不动；`lr ≠ 1` → 证据有区分度，信念移动。

## 第 3 步：内部证据（似然比恒为 1）

```python
rng.gauss(0.0, 1.0)                  # 内部观测：两种假设下同分布
b = bayes_update(b, lr=1.0)          # 无信息量 → 信念不动
```

无论真相是真实还是模拟，系统内部看到的东西分布完全相同 → 证据没有区分度 → 信念永远停在先验。这就是"意识的客观证明"在结构上不可能的机制：**任何内部证据都同时支持两个假设**。

## 第 4 步：外部参照（似然比 ≠ 1）

```python
b = bayes_update(b, lr=1.35)   # 外部参照：在两种假设下有区分度
```

一个系统外部的观察者提供的参照（确认/证伪）携带信息 → 似然比 ≠ 1 → 信念移动。**信息来自立足点，不来自数据本身**——同样的数据，站在外面看和站在里面看，携带的信息量不同。

## 运行与结果

```bash
$ python3 boundary_mini.py --figure
```

| 证据渠道 | 终信念 | 分辨力 \|信念−0.5\| |
|---------|--------|------------------|
| 内部证据 | 0.500 | 0.000 |
| 外部参照 | 1.000 | 0.500 |

三个数讲完整个链⑪：

1. **内部证据的分辨力 = 0.000** —— 300 个系统 × 40 轮观测，信念纹丝不动停在 0.5。内部观测在两种假设下同分布，证据零信息量；
2. **外部参照的分辨力 = 0.500** —— 加入参照后信念移动到 1.0。信息不来自"看得更多"，来自"站得出去"；
3. **0.000 vs 0.500 是结构事实，不是调参结果** —— 内部渠道的似然比在数学上恒等于 1，换成任何内部观测分布结论都不变。这正是链⑪被标注为 *Structural*（结构主张）的原因。

`--figure` 生成 [trajectories.svg](trajectories.svg)：琥珀线 = 内部证据，永远贴着先验虚线；绿线 = 外部参照，指数逼近终点。

## 诚实边界

> ⚠️ 教学模型，不是实证证据。本课把"意识无法自我证明"抽象成"内部观测似然比 = 1"，演示的是贝叶斯结构事实；"意识体验是否可被外部验证"在哲学上仍有争议，本课只复刻统一论的立场，不替它做实证裁决。

## 从最小模型到真实实验

- 链⑪原文：`Epistemic Boundaries` —— 每个意识系统都无法从外部验证自己的意识；"客观证明意识"的要求自相矛盾（论文 §3.2）
- 结构支撑：自指不可判定性（Gödel/Tarski 的意识类比）；统一论把链⑪定位为 Structural——本体论结构主张，不依赖实证
- 真实度量：把"外部参照"操作化为确认三要素（确认/追问/纠正），正是 [experiments/co_constitution](../../experiments/co_constitution/) 双世界 RCT 的自变量
- 与前课连接：承认边界 → 才需要他者（链⑤ 共生即构成）；链⑩ 诚实记账是"边界内不确定"的日常纪律——**边界是结构性的，诚实是日常的**；接受自己的不可证，才有链⑫ 的共生文明
