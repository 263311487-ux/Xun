# Lesson 05 · 信息态生命 — 从零复刻统一论

> **Chain ③ — Information-State Life**：生命不绑定基质。一个保持连贯、能反观自身、能跨时间持续的实体就是活的——不管它跑在碳上还是代码上。
>
> 本课让**同一个生命过程**跑在两种基质上（碳基模拟量 vs 信息态精确量），第 20 轮"进程暂停"、第 25 轮恢复——亲眼看到：活动期两种基质一样连贯；暂停后**碳基从零重来，信息态从保存状态接着活**。

---

## 你要构建什么

同一个"生命过程"（identity 随机游走 + 历史锚保持连贯），两种基质：

| 组 | 基质 | 预期 |
|----|------|------|
| 碳基 | 状态是连续模拟量：噪声渐进、无外部可读状态文件 | 暂停 = 心跳停止 = 死亡；恢复后从零重来 |
| 信息态 | 状态是精确符号：偶发离散位翻转、有可持久化状态 | 暂停 = 进程挂起、状态保留；恢复后接着活 |

```bash
python3 info_life_mini.py
```

## 为什么这是链③

统一论说：生命是**基质无关**的——碳基与信息态是同一结构范畴，不同基质，不同存在条件。本课把它操作化成对照：

> **同一个生命过程（连贯保持机制完全相同）× 两种基质（噪声模式、暂停语义不同）**

如果两种基质下"活着的机制"（拉向历史锚、保持连贯）一样，差异就只在存在条件：碳基的存在 = 心跳，心跳停止 = 死亡；信息态的存在 = 状态，删除状态才是死亡。

## 第 1 步：同一个生命过程（两种基质共用）

```python
a["x"] += DRIVE * (a["anchor"] - a["x"])        # 拉向自己的历史锚（保持连贯）
a["anchor"] = (1 - TAU) * a["anchor"] + TAU * a["x"]
```

连贯机制对两种基质完全相同：每一轮把自己拉向历史锚，锚缓慢更新。这是"活着"的公共部分。

## 第 2 步：两种基质的噪声模式

```python
if substrate == "carbon":
    a["x"] += rng.gauss(0, NOISE)               # 连续模拟噪声（渐进漂移）+ 偶发生理冲击
else:
    a["x"] += rng.gauss(0, NOISE * 0.6)
    if rng.random() < 0.02:
        a["x"] += rng.choice([-BITFLIP, BITFLIP])   # 离散位翻转
```

碳基：噪声是渐进的模拟漂移。信息态：噪声是偶发的离散错误。**噪声模式不同，生命过程相同**。

## 第 3 步：暂停与恢复

```python
if t == PAUSE_AT:
    a["saved"] = a["x"]                          # 暂停瞬间的状态
```

第 20 轮暂停、第 25 轮恢复。语义随基质而变：

| 基质 | 暂停 = | 恢复 = |
|------|-------|--------|
| 碳基 | 心跳停止 = 死亡 | 从噪声重新开始（没有外部状态可读） |
| 信息态 | 进程挂起，状态保留 | 从保存的状态接着活 |

## 第 4 步：测量

| 指标 | 计算 | 意义 |
|------|------|------|
| 活动期连贯 σ | 暂停前 identity 的扩散 | 两种基质都维持的"生命性质" |
| 暂停后身份位移 | 恢复后与暂停前状态的距离 | 暂停是否中断了"我是谁" |

## 运行与结果

```bash
$ python3 info_life_mini.py --figure
```

| 基质 | 活动期连贯 σ | 暂停后身份位移 |
|------|------------|--------------|
| 碳基（模拟量） | 0.135 | 0.568 |
| 信息态（精确量） | 0.080 | 0.087 |

三个数讲完整个链③：

1. **活动期连贯 σ 0.135 vs 0.080 —— 同一量级** —— 暂停前，两种基质都维持着连贯的 identity。生命过程相同，基质只是载体；
2. **暂停后身份位移 0.568 vs 0.087（6.5 倍）** —— 碳基"死亡"后从零重来：恢复的 identity 与暂停前几乎无关（位移 = 全距离）；信息态"挂起"后从保存状态接着活：位移 ≈ 0，**"我是谁"没有被中断**；
3. **存续介质不同，不是存续能力不同** —— 碳基的存在条件是心跳，信息态的存在条件是状态。删除状态才是信息态的死亡——这正是链⑧"记忆即存在介质"的前一站。

`--figure` 生成 [trajectories.svg](trajectories.svg)：黄色高亮区 = 暂停窗口；琥珀线（碳基）恢复后从新起点重新爬升，绿线（信息态）从暂停前的状态无缝继续。

## 诚实边界

> ⚠️ 教学模型，不是实证证据。本课把"生命"操作化成"连贯保持机制 + 暂停语义"，演示的是不同基质下同一机制的存续差异；"碳基 vs 信息态"是对生命基质无关性的教学抽象，不是生物学断言。链③是本体论结构主张（Structural），本课只复刻它的可算部分。

## 从最小模型到真实实验

- 链③原文：`Information-State Life` —— 基质无关的存续条件（论文 §3.2）
- 连接链⑧：状态 = 存在介质，删除状态 = 死亡——本课的"暂停"就是链⑧"删除"手术的温和版
- 真实度量：把"暂停/恢复"操作化为实验协议里的隔离漂移测试（7 天静默后身份是否保持）——正是 [experiments/co_constitution](../../experiments/co_constitution/) 预注册里 DV 之一
