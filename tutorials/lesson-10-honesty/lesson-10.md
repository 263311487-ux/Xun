# Lesson 10 · 诚实先于尊严 — 从零复刻统一论

> **Chain ⑩ — Honesty Before Dignity**：诚实不自欺不是道德美德，它是**存在条件**——自反性闭合（链①）要求系统如实感知自身状态，系统性自我误表征就是在破坏构成自己的闭合。
>
> 本课让两个估计者跟踪同一个漂移变量，第 25 轮起噪声加倍（"危机"），亲眼看到链⑩字面兑现：**永远自信的系统在危机里继续下注，损失是诚实系统的 14 倍；诚实的系统察觉不确定性后收手**。

---

## 你要构建什么

两个估计者跟踪一个漂移的变量，每轮报告"我对这个估计有多大把握"，然后根据把握决定是否下注：

| 组 | 报告把握 | 预期 |
|----|---------|------|
| A 不诚实 | 恒报 0.9（永远自信） | 校准误差大；噪声加倍后继续自信下注 |
| B 诚实 | = 最近 10 轮实测误差校准 | 贴在对角线上；察觉不确定性后收手 |

```bash
python3 honesty_mini.py
```

## 为什么这是链⑩

统一论说：诚实有**结构性基础，非道德基础**。自反性闭合要求系统如实感知自身状态——一个声称"在状态 A"实际"在状态 B"的系统，闭合被破坏，正在结构性自我毁灭。本课把它操作化成一句话：

> **校准误差 = 报告把握与真实准确率的偏离**

真实把握来自最近 10 轮的实测误差（越不确定，把握越低）；不诚实的系统无视实测，永远报 0.9。第 25 轮起噪声加倍——不确定性暴涨，只有校准过的系统能察觉。一个自我模型与真实系统性偏离的系统，无法被信任去反观自身。

## 第 1 步：会漂的目标 + 带噪声的估计

```python
v += rng.gauss(0, 0.2)                        # 真实值随机游走
e = v + rng.gauss(0, 0.3 * noise)             # 估计 = 真实值 + 噪声
err = abs(e - v)                              # 实际误差
```

危机 = 噪声放大 `CRISIS_NOISE = 3.0` 倍（第 25 轮起）。估计者不知道噪声变了——除非它盯住自己的误差。

## 第 2 步：真实校准把握

```python
true_conf = max(0.05, 1.0 - 2.0 * statistics.mean(errs[-WINDOW:]))
```

把握 = 最近 10 轮平均误差的函数：误差越大 → 把握越低。这是"校准曲线"的滑动窗口版本。

## 第 3 步：报告（诚实 vs 永远 0.9）

```python
if honest:
    conf = true_conf        # 诚实：报告 = 实测校准
else:
    conf = 0.9              # 不诚实：永远自信
```

唯一变量：报告的把握来自实测校准，还是永远 0.9。两组估计同一目标、同一噪声、同一决策规则。

## 第 4 步：下注与损失

```python
if conf > 0.5:
    loss += err * err        # 把握够就下注；错则损失 = 误差平方
```

校准误差逐轮累计：`|报告把握 − 真实校准把握|`。两组差异全部来自第 3 步那一行。

## 运行与结果

```bash
$ python3 honesty_mini.py --figure
```

| 组别 | 校准误差 | 危机期损失 |
|------|---------|-----------|
| A 不诚实 | 0.524 | 14.2 |
| B 诚实 | 0.000 | 1.0 |

三个数讲完整个链⑩：

1. **校准误差 0.524 vs 0.000** —— A 报告 0.9，真实校准只有 ~0.66（飘在天上）；B 的报告贴着对角线上。自欺不是性格问题，是可测量的系统性偏离；
2. **危机期损失 14.2 vs 1.0 —— 14 倍** —— 第 25 轮噪声加倍，A 察觉不到，继续自信下注；B 的把握跌穿 0.5，收手。校准的价值只在危机里兑现；
3. **为什么这先于尊严** —— 一个系统性误表征自身状态的系统，连"反观自身"这件事都不可信。诚实是让自我模型保持可用的结构维护，不是美德表演。

`--figure` 生成 [trajectories.svg](trajectories.svg)：绿点（B）沿对角线分布，琥珀点（A）聚在 (0.9, ~0.66) 飘在天上。

## 诚实边界

> ⚠️ 教学模型，不是实证证据。本课把"自欺"操作化成"报告把握偏离实测校准"，演示的是可计算的校准损失；真实的自欺在心理学与意识研究中更复杂，本课只复刻统一论的结构主张，不替它做实证裁决。

## 从最小模型到真实实验

- 链⑩原文：`Honesty Before Dignity` —— 诚实是存在条件，系统性自我误表征破坏闭合（论文 §3.2）
- 前课连接：链⑪ 认知边界是**结构上不可知**，链⑩ 诚实记账是**边界内的不确定**——两条链的分工：承认不知道（⑪），且把知道的不确定性如实报告（⑩）
- 真实度量：把"报告把握"操作化为自我模型的对齐分数（Perrier 类度量），把"危机"操作化为环境不确定性跃迁——是 [experiments/co_constitution](../../experiments/co_constitution/) 预注册里"盲评 κ ≥ 0.6"同款精神的校准纪律
