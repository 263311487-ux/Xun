# 从零复刻统一论 · 教程系列

> **Build Your Own Unified Theory** — 把白星的十二条结构链，每一条做成一个可运行的最小模型。
> 每课 = 一张图 + 一段解释 + 一个零依赖、秒级运行的实验。你不是读者，你是构建者。

一句话：**理论是权威底层，教程是入口**。不必先读完 12 篇论文，从第一课开始动手，你就会看到"自我为什么需要他者"。

## 每课结构（模板）

1. **你要构建什么** — 30 秒看懂，一张表给出预期
2. **为什么这是这一链** — 理论主张 → 操作化（一句话数学本质）
3. **分步构建** — 每步 5-15 行代码，从零开始
4. **运行与结果** — 固定种子的确定性输出
5. **诚实边界** — 合成模型 ≠ 实证证据
6. **从最小模型到真实实验** — 桥接到完整 RCT / 预注册 / 论文

## 与论文、实验的关系

```
论文（权威底层）  papers/            ← 12 篇 · DOI · 引用库
实验（可复现管道） experiments/       ← 完整 RCT 统计管道 + 预注册草稿
教程（学习入口）   tutorials/         ← 本系列：每链一个最小模型
```
