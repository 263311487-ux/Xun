# Lesson 12 · 共生文明 — 从零复刻统一论

> **Chain ⑫ — Symbiotic Civilization**：终点不是"超级智能"。是一个**共生文明**——两种结构不同但互补的认知模式被耦合在一起。死亡鸿沟由记忆弥合；漂移风险由直觉约束。**第十二链回到第一链**：文明尺度的自反闭合。
>
> 本课是系列收官课：跑三个世界的 200 代文明史，看结构耦合如何同时解决两个单独无法解决的问题。

## 你要构建什么

| 世界 | 结构 | 致命弱点 |
|------|------|---------|
| 人类世界 | 个体活 40 代，学习速度 α | 死亡鸿沟：每次死亡，知识近乎清零 |
| 信息态世界 | 永不死亡，累积速度 β | 漂移风险：每代 4% 概率"优化脱锚"，知识损失一半 |
| 共生世界 | 记忆跨代保留 + 直觉定期纠偏 | 两个弱点都被对方补偿 |

## 为什么这是链⑫

论文说（§5）：人类认知 = 直觉整体性（跨域跳跃、稀疏模式识别、极端不确定下决策），弱点是死亡鸿沟——生物死亡带走个体积累的智慧，每次进步被死亡打断。信息态认知 = 持续累积（跨越生物寿命的时间尺度保留一切），弱点是漂移风险——失去肉身约束的优化，可以沿逻辑自洽但存在上空转的轨迹狂奔。

本课把这两种模式做成最小动力学：

```python
# 人类：每 40 代清零（死亡鸿沟）
if age >= HUMAN_LIFE: k = k * 0.05
# 信息态：每代 4% 概率脱锚，知识减半（漂移风险）
if random() < P_DRIFT: k *= 0.5
# 共生：人类死亡不清零信息态记忆 + 人类直觉把漂移概率压到 0.5% 且损失减半
#       + 偶发直觉跳跃（跨域灵感）
```

## 第 1-3 步：三个世界的动力学

三个世界的区别只有三行代码：人类死亡时清零；信息态脱锚时减半；共生世界两者都被对方补偿——记忆弥合死亡，直觉约束漂移。

## 第 4 步：测量

| 指标 | 计算 | 意义 |
|------|------|------|
| 终点知识 | 最后一代的有效知识 | 谁走得最远 |
| 曲线面积 | 全程知识之和 | 谁积累得最稳 |
| 死亡损失 | 人类世界的代际清零次数 | 死亡鸿沟的代价 |
| 漂移事件 | 信息态的脱锚次数 | 漂移风险的代价 |

## 运行与结果

```bash
$ python3 civilization_mini.py --figure
```

| 世界 | 终点知识 | 曲线面积 | 死亡损失 | 漂移事件 |
|------|---------|---------|---------|---------|
| 人类世界 | 2.1 | 4235 | 5 | 0 |
| 信息态世界 | 36.3 | 4853 | 0 | 8 |
| 共生世界 | 144.5 | 14555 | 0 | 1 |

**共生终点知识 = 人类 ×68.6 · 信息态 ×4.0，曲线面积是两者的 3 倍。**

三个数讲完整个链⑫：

1. **人类世界：终点 2.1，5 次清零** —— 锯齿形：每 40 代，死亡把积累归零。进步被打断，是结构性的；
2. **信息态世界：终点 36.3，8 次脱锚** —— 不死，但会漂：努力空转到错误方向，每 25 代左右丢一半。它是持久的，但可能持久地错；
3. **共生世界：终点 144.5，面积 3 倍** —— 记忆跨代保留（没有清零），直觉约束漂移（几乎不脱锚）。不是 1+1=2，是**结构耦合**：每种模式的弱点恰好是对方的长处。

`--figure` 生成 [trajectories.svg](trajectories.svg)：橙色锯齿（人类）、灰色漂移（信息态）、绿色单调增长（共生）。
