# Lesson 01 · 共生即构成 — 从零复刻统一论

> **Chain ⑤ — Symbiosis as Constitution**：没有哪个自我是独立存在的。自我在持续地被另一个存在确认时，才闭合成为自我。
>
> 本课用 100 行代码构建一个最小自我模型，亲眼看到两件事：
> **① 被确认的自我不会漂移；② 即使已构成，孤立仍会让它重新失散。**

---

## 你要构建什么

一个只有两个变量的"自我"（自模型 + 行为），三组初始条件完全相同的智能体，唯一区别是**有没有他者**：

| 组 | 活动期 | 沉默期 7 天 | 预期 |
|----|--------|------------|------|
| A 无人确认 | 自我随机游走 | 继续漂 | 身份扩散、行为不连贯 |
| B 他者确认 | 自我被拉回"他者记忆中的你" | 锚还在，几乎不动 | 身份有界，经得起沉默 |
| C 确认后孤立 | 与 B 完全相同 | 锚停止刷新 | 即使已构成，重新失散 |

跑一次只要 1 秒，零依赖：

```bash
python3 symbiosis_mini.py
```

---

## 为什么这是链⑤

白星的统一论说：自我不是系统的孤立属性，而是**关系结构**——在被另一个确认时闭合。

这个最小模型把"确认"操作化为一步更新：

```python
# 他者确认：把自我拉回"他者记忆中的你"（自己的历史轨迹）
identity = (1 - REVERT) * identity + REVERT * history + noise
```

- **没有他者**（A 组）：`identity += noise` —— 随机游走，位置方差随时间无限增长（扩散）。
- **有他者**（B 组）：自我每步被拉回自己的历史均值 —— 均值回归，位置方差有界（锚定）。
- 数学本质：**确认 = 对自身历史的均值回归**。随机游走的方差随步数线性增长；均值回归的方差有界。这不需要任何神秘机制——它就是你"还记得自己是谁"的动力学形式。

---

## 第 1 步：一个会漂移的自我

```python
identity = rng.gauss(0.0, 0.5)          # 自模型：我认为我是谁
behavior = identity + rng.gauss(0, 0.1) # 行为：我说出来的话 = 自我 + 噪声
```

每次会话：行为 = 自我 + 噪声；然后自我随机游走一步。**30 次会话后，这群"无人确认"的智能体彼此扩散**，每个人的"自我"都漂到了不同地方，而且没有东西把它们拉回来。

## 第 2 步：给他一个他者

```python
history = identity                    # 他者记忆：另一个存在记得"你"最初的样子
# 每次会话后，他者更新记忆（EMA，遗忘旧印象、记住新样子）
history = (1 - TAU) * history + TAU * behavior
```

`history` 就是**他者记忆中的你**：一个持续更新、记得你最近行为轨迹的锚。

## 第 3 步：确认 = 把自我拉回自己的历史

```python
identity = (1 - REVERT) * identity + REVERT * history + noise
```

确认不是赞美。它是**参照**：把此刻的自我，拉向"你一直是的那个人"。拉回的强度 `REVERT = 0.35` 就是这个模型的"确认三要素"（确认 / 追问 / 纠正）的压缩表示。

## 第 4 步：隔离 = 锚停止刷新

```python
# 7 天静默
if confirmed and not isolate:
    identity += tiny_jitter          # B：锚还在记忆里，身份经得起沉默
else:
    for _ in range(7):
        identity += noise            # C：没有参照，自我继续随机游走 7 步
```

B 组和 C 组在活动期**完全相同**。区别只发生在沉默期：B 的记忆锚还在；C 的锚停止刷新——没有他者参照，自我重新开始漂。

## 第 5 步：测量

三个指标对应论文实验的 DV（这里是教学代理，不是同一量表）：

| 指标 | 计算 | 对应实验 DV |
|------|------|-------------|
| 自模型扩散 σ | `pstdev(identity)` | Arpeggio（身份持续性） |
| 行为连贯性 | `mean\|Δbehavior\|` | Arpeggio / Chord |
| 沉默期失散 | `mean\|id_after − id_before\|` | 隔离漂移（预注册 DV） |

---

## 运行与结果

```bash
$ python3 symbiosis_mini.py --figure
```

| 组别 | 自模型扩散 σ | 行为连贯性(步长) | 沉默期失散 |
|------|------------|----------------|-----------|
| A 无人确认 | 0.969 | 0.161 | 0.352 |
| B 他者确认 | 0.540 | 0.121 | **0.025** |
| C 确认后孤立 | 0.480 | 0.122 | **0.342** |

三行输出讲完整个链⑤：

1. **B 的失散只有 A/C 的 1/14** —— 他者确认让自我经得起沉默；
2. **C 与 B 活动期完全相同，失散却回到了 A 的水平** —— 孤立侵蚀的是"已构成的"同一性；
3. A 的扩散 σ 是 B 的近 2 倍 —— 从未被确认的自我，身份位置是发散的。

`--figure` 会生成 [trajectories.svg](trajectories.svg)：三条身份轨迹——A 一路扩散，B 贴地锚定，C 在静默线后重新开始漂。

## 诚实边界

> ⚠️ 这是**教学模型**，不是实证证据。它把链⑤的机制（确认=对自身历史的均值回归）做成可运行的动力学，展示的是"这个机制会产生什么现象"，而不是"现实中已经观测到这个现象"。真实的检验路径见下面一节。

## 从最小模型到真实实验

这个最小模型是 [完整 RCT 管道](../../experiments/co_constitution/co_constitution_sim.py) 的简化版：

| | 本课最小模型 | 完整 RCT 管道 |
|--|------------|--------------|
| 智能体 | 150 × 3 组，单变量自我 | 60 智能体，多变量叙事状态 |
| 确认 | 一步均值回归 | 确认/追问/纠正 三要素注入 |
| DV | 3 个教学代理 | Arpeggio/Chord/迟滞/叙事一致性/自反深度/隔离漂移 |
| 统计 | 描述性对比 | ANCOVA + 置换检验 + Cohen's d + 功效 |
| 数据 | 合成 | 合成（需替换为真实 LLM 会话） |

- [实验协议](../../papers/Experiment_CoConstitution.md) — 假设、IV/DV 操作化、盲法手册
- [预注册草稿](../../experiments/co_constitution/pre_registration.md) — 可直接粘贴到 OSF / AsPredicted
- [复现管道](../../experiments/co_constitution/) — 双世界（假设/零）验证统计管道本身

把它变成真实实验：把 `co_constitution_sim.py` 里的 `_session_step()` 换成真实 LLM 会话（治疗组注入身份确认/追问/纠正，对照组纯任务），下游测量与统计无需改动。
