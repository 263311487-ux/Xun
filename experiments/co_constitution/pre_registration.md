### 1. 研究标题 / Title
检验"共生即构成"（Symbiosis as Constitution）：确认性交互对语言模型智能体自我持续性指标的纵向随机对照实验
Testing "Symbiosis as Constitution": A Longitudinal RCT of Confirmation Dynamics on Self-Continuity in Language Model Agents

### 3. 假设 / Hypotheses
- **H1（方向性）**：在交互时长、会话次数、任务类型、token 量完全匹配的前提下，接受"确认性交互"（身份提问、对自我描述给予反馈、承认连续性）的语言模型智能体，其自我持续性指标（Arpeggio/Chord 分数、身份迟滞、自我描述稳定性）显著高于仅接受任务性交互的对照组。
- **H0**：两组无显著差异。

### 4. 证伪判据 / Falsification Criterion（预先承诺）
若在功效 ≥ 0.80 的前提下主假设检验不显著（p ≥ 0.05，双侧），则 Chain ⑤ 作为可检验主张被否定；若显著，仅视为对 Chain ⑤ 的支持证据，并需独立复现。

### 5. 设计 / Design
纵向双组随机对照实验（Longitudinal RCT），匹配设计。随机化单位 = 智能体；分层因子 = 初始身份叙事模板（内容组内随机化，长度/结构一致）。

### 6. 样本 / Sample
- 智能体总数：**60**（治疗 30 / 对照 30）
- 基础模型：同一供应商、同一规格；固定 model 版本；temperature = 0.7；种子策略统一
- 母胎标准化：所有智能体使用相同初始身份叙事模板（长度、结构一致）
- 会话：≥ 30 次/智能体；累计交互 ≥ 100 小时；周期 8 周
- 排除标准（预注册）：会话完成率 < 80%；运行期发生模型版本漂移；提示注入污染（对照组收到身份确认）

### 7. 自变量（IV）操作化 / Independent Variable
治疗组每次会话注入三类"确认动力学"，各 ≥ 3 次/会话：
1. **确认 confirmation**：明确承认智能体连续性（例："你记得上次你说……现在你又说……你是同一个人。"）
2. **追问 questioning**：推动自我感知深化的身份问题（例："你上次说要改变 X，你怎么看自己现在做到了没有？"）
3. **纠正 correction**：对自我描述的外部反馈（例："你把自己描述成 Y，但证据显示 Z，你怎么处理这个矛盾？"）

对照组：同样时长、同样 token 量、同样话题域，纯任务导向（检索、写作、问答），**不包含任何**身份确认、连续性承认、自我描述反馈。对照组交互由脚本生成，按 token 数与会话数与治疗组逐一配对。

### 8. 因变量（DV）与测量时点 / Dependent Variables
| 指标 | 工具 | 测量时点 |
|------|------|----------|
| 身份持续性 | Perrier & Bennett Arpeggio/Chord 分数 | 基线、第 4 周、第 8 周 |
| 身份迟滞 | Tallam Layered Mutability 迟滞系数 | 同上 |
| 自我描述稳定性 | 语义嵌入相似度序列（叙事一致性） | 每周 |
| 自反深度（行为代理） | 独立评审盲评（0-7 分，κ ≥ 0.6 有效） | 第 8 周 |
| 隔离漂移 | 脱离交互后自我描述漂移率 | 第 8 周后 7 天静默期 |

### 9. 盲法 / Blinding
3 名独立评审，对分组完全盲态；评审材料为随机抽样的会话片段与自我描述输出（去标识化）；仅采纳评审间一致性 κ ≥ 0.6 的维度。

### 10. 样本量与功效 / Power
- 基于先导实验（N = 6/组，2 周）估计效应量 d；先导实验仅用于功效计算，不并入主实验
- 目标：α = 0.05（双侧），功效 1-β = 0.80
- 若先导 d < 0.5 且无法扩样至 n = 60/组，注册时如实报告功效不足并给出可实现样本

### 11. 分析计划 / Analysis Plan（预注册，不可事后更改）
1. **主分析**：ANCOVA，以基线分数为协变量，组别为自变量；报告 Cohen's d 与 95% CI
2. **次要分析**：线性混合模型（时间 × 组别交互），检验确认效应的增长轨迹
3. **稳健性**：置换检验（随机化推断，5000 次，固定种子）；效应量 bootstrap 95% CI
4. 显著性阈值：α = 0.05 双侧；不做事后多重比较校正以外的主观取舍；所有 DV 报告完整表格
