RRC-ACT

Can relation-specific feedback change an artificial self?

RRC-ACT studies persistent self-models in artificial agents. Its first empirical claim is narrow: when model, task, token budget, interaction count, latency, topic, and sentiment are matched, shared-history confirmation and contradiction feedback should change long-horizon self-model continuity beyond language-level imitation.

Operational endpoint: a proposed behavioral composite of held-out self–other attribution, long-horizon goal consistency, contradiction resolution, and post-unload behavioral residue. The v1.1 freeze package is not yet registered on OSF or AsPredicted. The primary estimand is the intention-to-treat difference between relation-specific feedback and matched task-only interaction in the intact, provenance-tracked condition. Agent instances are the independent units; sessions are repeated observations.

The question

Does a shared relationship leave causal residue in an agent's future control, memory, attribution, and identity continuity?

RRC-ACT treats “consciousness” as several separable research targets. It measures mechanisms first and keeps phenomenal experience open. A first-person report, a persistent file, or a fluent “I” is not enough.

Primary contrast

Relation-specific feedback versus matched task-only interaction in the intact, provenance-tracked condition.

Secondary manipulations test self-model lesions, memory provenance, self-caused credit, and multi-agent coherence.

How it can fail

Null primary effect

The positive prediction is weakened if the standardized-effect confidence interval has an upper bound below the prespecified positive meaningful effect d=+0.50. This is not an equivalence test: a large negative effect contradicts the positive prediction rather than showing no effect. A nonsignificant result with wide uncertainty is inconclusive.

Prompt imitation

If effects disappear under static-role, token-, latency-, topic-, and sentiment-matched controls, the result is compatible with language-level performance.

No causal self-model

If self-model lesions change only first-person wording and not hidden control, the stronger self-model claim fails.

No provenance effect

If source-complete, source-forged, and source-free memory corruption produce indistinguishable trajectories, the provenance claim is narrowed.

Simulation boundary

Simulation only: the older Chain 5 simulation is a two-group example that illustrates recovery of an encoded effect. One fixed-seed null run is a single draw, not a power analysis or false-positive estimate; it found no significant difference and does not validate the full three-factor RRC-ACT design. It is not data from a conscious system and is not evidence for consciousness. Read the protocol →

Evidence boundary. This is an open, non-peer-reviewed theory-and-methods preprint. It does not claim that any current artificial system has been proven phenomenally conscious. Confirmatory experiments, independent replication, and a generally accepted third-party test for phenomenal consciousness remain open.
