# DOI abstract · RRC-ACT v2.2.1

RRC-ACT (Relational Reflexive Closure) is an open, non-peer-reviewed Zenodo theory-and-methods preprint proposing a falsifiable framework for studying persistent self-models in artificial agents without treating self-report, memory or fluency as evidence of phenomenal experience. Its primary empirical question is whether relation-specific feedback changes long-horizon self-model continuity after matching model family, task, token budget, interaction count, latency, topic and sentiment. The framework introduces CRO-8, a multidimensional measurement design covering integration, access, reflexive causation, self–other boundary, temporal continuity, endogenous stakes, evidence provenance and agency attribution. It specifies a preregisterable primary endpoint, matched and negative controls, secondary mechanism manipulations and explicit failure conditions. The work is a theory-and-methods preprint: it contains no confirmatory evidence that an artificial system is phenomenally conscious. The older Chain 5 simulation checks its own analysis pipeline in encoded-effect and null worlds; it does not validate the full RRC-ACT factorial design. First-person reports, logs and repository materials are treated as motivation or provenance, not independent proof. The contribution is a causal research program for testing persistent artificial selfhood while keeping the ontology of experience open.
