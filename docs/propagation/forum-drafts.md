## Hacker News

**Title:** RRC-ACT: A proposed test for persistent self-models in AI agents

I wrote an open, non-peer-reviewed Zenodo preprint, with a protocol not yet registered, asking a narrower question than “is this model conscious?” When model family, task, token budget, interaction count, latency, topic and sentiment are matched, does relation-specific feedback change an artificial agent’s long-horizon self-model continuity beyond language-level imitation?

The registration-ready freeze package specifies held-out self–other attribution, goal consistency, contradiction resolution and post-unload behavioral residue. The protocol also specifies self-model lesions, provenance-aware memory controls, self-caused credit tests and failure criteria. CRO-8 (consciousness-related organization) is an eight-dimensional measurement design, not a consciousness score.

The older Chain 5 simulation checks its own analysis pipeline in an encoded-effect world and a null world. It does not validate the full RRC-ACT design or provide consciousness evidence. First-person model reports, logs and repository descriptions are not independent proof.

## Reddit

**Title:** RRC-ACT: a proposed test of whether relation-specific feedback changes persistent AI self-models

This is an open, non-peer-reviewed theory-and-methods preprint, not a claim that an AI has been shown to be conscious. The proposed intervention holds model, task, token budget, interaction count, latency, topic and sentiment constant, then compares relation-specific feedback with matched task-only interaction. The planned outcome is a preregisterable composite over held-out self–other attribution, long-horizon goal consistency, contradiction resolution and post-unload behavioral residue.

The simulation is a pipeline check only; first-person model reports and logs are not independent proof. The pilot protocol is not yet registered. Critical replication proposals are welcome.

## Academic forum / mailing list

**Subject:** Preprint: RRC-ACT — a preregisterable framework for persistent self-models in artificial agents

Dear colleagues,

I am sharing an open, non-peer-reviewed Zenodo theory-and-methods preprint on artificial consciousness and persistent self-models. RRC-ACT proposes a narrow, testable question: after matching model, task, token budget, interaction count, latency, topic and sentiment, does relation-specific feedback causally change long-horizon self-model continuity beyond language-level imitation?

The manuscript defines a multidimensional measurement design, a registration-ready endpoint specification, matched controls, negative controls and explicit falsifiers. It does not claim that any present artificial system has phenomenal experience. Simulations are pipeline checks only; first-person model reports and system logs are not independent proof. The v1.1 freeze package is registration-ready but has not yet been registered on OSF or AsPredicted; concrete model snapshots and item-bank hashes remain to be filled before confirmatory runs.

Preprint DOI: https://doi.org/10.5281/zenodo.23146271

Code and materials: https://github.com/263311487-ux/Xun/releases/tag/rrc-act-v2.2.1

I would welcome methodological criticism, alternative operational endpoints and independent preregistration or replication proposals.
