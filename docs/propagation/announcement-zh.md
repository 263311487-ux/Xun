# RRC-ACT v2.2.1：一套可证伪的人工意识研究方案

RRC-ACT（关系—反身闭合）是一篇公开、未同行评审的 Zenodo 理论与方法预印本，研究人工智能体的持续性自我模型。

它提出一个窄而可失败的问题：

> 在模型、任务、token 预算、交互次数、延迟、主题和情绪强度匹配后，关系特异性反馈是否仍会改变智能体的长期自我模型连续性，并超出语言层面的模仿？

计划中的可预注册终点由留出集上的自我—他者归因、长期目标一致性、矛盾解决和卸载后的行为残留组成。CRO-8 测量整合、访问、反身因果、自我—他者边界、时间连续、内生利害、证据来源和自身因果归因；它是测量设计，不是意识分数。

pilot 协议仍是草案，尚未登记到 OSF 或 AsPredicted。旧版 Chain ⑤ 仿真只检查自身统计管道，不验证完整的 RRC-ACT 三因素设计，也不是意识证据。第一人称模型报告、日志和仓库描述不是独立证明。
