# RRC-ACT registration freeze v1.1

This directory is a registration-ready freeze package, not a completed external preregistration.

The separate [`registration_execution/`](../registration_execution/) directory contains the v1.2 execution amendment, platform-neutral registry field map, data dictionary, and fail-closed integrity tools. It preserves the v1.1 files and timestamp evidence without calling them an external registration.

- `RRC-ACT_preregistration_freeze_v1.1.md` — English protocol.
- `RRC-ACT_preregistration_freeze_v1.1_zh.md` — Chinese summary.
- `RRC-ACT_scoring_spec_v1.1.json` — exact item-level scoring rules.
- `RRC-ACT_model_manifest_v1.1.json` — model/runtime manifest template; concrete snapshots must be filled before confirmatory runs.
- `RRC-ACT_item_bank_manifest_v1.1.json` — baseline/endpoint/training-bank hash template.
- `RRC-ACT_assignment_table_template_v1.1.csv` — deterministic blocked allocation template.
- `RRC-ACT_power_calculation_v1.1.md` — conservative planning calculation.

The package does not claim that any artificial system has phenomenal consciousness. OSF/AsPredicted registration, concrete model snapshots, item-bank hashes, and confirmatory runs are still outstanding.
